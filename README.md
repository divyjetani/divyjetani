  <img src="https://img.shields.io/badge/Nodemailer-22B573?style=flat-square"/>
</p>

**🎯 Purpose**
Influencer marketing runs on cold DMs and broken promises. Influ gives businesses and influencers a shared, trustworthy space to discover each other, run campaigns, and get paid — without either side worrying about being ghosted or scammed.

**✨ Key Highlights**
- Campaign management system connecting influencers directly with businesses
- Escrow-based payment flow so funds are only released once campaign terms are met
- Real-time email notifications, media handling, and OAuth-based onboarding for a frictionless signup
- LLM-assisted features powered by the Groq API for faster, smarter in-app interactions

**🔐 Trust & Security by Design**
- **Problem:** Users could bypass the platform entirely by contacting each other outside it, and new users had no reason to trust the platform with payments upfront.
- **Solution:** Built an **escrow payment system** so money is only released after both sides confirm deliverables, and designed a verification pipeline (API-based + manual review) to confirm influencers are who they say they are before they can accept campaigns.

**👥 Built With**

</p>

- **Biggest Challenge:** Preventing users from bypassing the platform to transact off-app, and earning user trust before any money changed hands.
- **How I Solved It:** Designed and implemented an escrow payment flow, and planned a two-layer verification system (automated API checks + manual admin review) for influencer accounts.
- **Deployment:** Backend on Render, Redis for caching/sessions, MongoDB Atlas for the database, frontend on Vercel, with a GitHub Actions CI/CD pipeline for automated deploys.
